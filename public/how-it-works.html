So funktioniert AegisChat

Maximale Privatsphäre durch Ende-zu-Ende-Verschlüsselung, automatischen 23:59 Uhr Wipe, Stimmverfremdung und anonyme Burner-IDs.

🔐 Zero-Knowledge E2EE

Alle Nachrichten und Dateien werden mit WebCrypto API (ECDH P-256 + AES-GCM-256) direkt im Browser verschlüsselt. Der Server liest ausschließlich Geheimtext.

🧹 23:59 Uhr Server-Reset

Pünktlich um 23:59 Uhr (Europe/Berlin) bereinigt das System ausnahmslos alle ausgetauschten Nachrichten und Uploads serverseitig unwiderruflich.

🎭 Voice Masking

Web Audio API BiquadFilter Chains erlauben Live-Stimmverfremdung bei verschlüsselten P2P WebRTC Anrufen direkt im Browser.

🧮 Stealth-Identitäten

Aktiviere den Stealth-Modus, um Seitentitel und Favicon im Handumdrehen z. B. als Taschenrechner oder Notiz-App zu tarnen.
